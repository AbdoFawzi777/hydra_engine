# Hydra Engine (`hydra_engine`)

A Flutter package for multi-protocol authentication testing and access control resilience evaluation.

## ✨ Features

- **Access Control Auditing**: Evaluates password strength and login resilience.
- **Multi-Protocol Support**: Structured interfaces for network login protocols.
- **Concurrent Testing**: Multi-threaded execution for high performance.
